# Security policy

## Supported versions

Only the latest published release is supported. Do not expose a Jellyfin administrator account to untrusted users.

## Reporting a vulnerability

Please do not publish security-sensitive details in a public issue. Until a dedicated contact is configured, open a private GitHub security advisory in this repository and include:

- Jellyfin and FamilyGuard versions;
- a minimal reproduction path;
- impact and any workaround.

Reports are acknowledged as soon as possible. A fix and coordinated disclosure will be preferred when a vulnerability affects protected-profile access.

## Scope

FamilyGuard is an assistant to Jellyfin's native parental controls, not a replacement for server security, account security, or parental supervision.
