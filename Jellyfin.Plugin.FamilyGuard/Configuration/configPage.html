Profiles and rules

Each profile corresponds to a Jellyfin user configured with its allowed tag in native parental controls. FamilyGuard only adds or removes the two tags below; it never changes files.

Native Jellyfin protection

Apply the selected profile's allowed tag directly to its linked Jellyfin account. This is enforced by the server on every authenticated client. Review the preview before applying; FamilyGuard preserves unrelated allowed tags and can remove only the tags it previously managed.
